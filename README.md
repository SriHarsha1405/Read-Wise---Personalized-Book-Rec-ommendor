# 📚 **Read-Wise Personalized Book Recommender**

A **Book Recommender System** designed to help users discover new books based on their preferences. The system uses a combination of **collaborative filtering** and **content-based filtering** algorithms to suggest books similar to those users have previously enjoyed.

---

## 🚀 **Overview**

This project is a **Book Recommender System** built to assist users in finding new books tailored to their interests. It leverages machine learning techniques to generate meaningful and relevant suggestions.

---

## 🔑 **Features**

- **User-Friendly Interface** – Simple and intuitive design for easy navigation  
- **Personalized Recommendations** – Provides suggestions based on user preferences  
- **Collaborative Filtering** – Uses user ratings and preferences to suggest books liked by similar users  
- **Content-Based Filtering** – Recommends books based on features of books the user has enjoyed using **cosine similarity**

---

## 🛠️ **Technologies Used**

- **Backend:** Python  
- **Frontend:** Streamlit  
- **Data Handling:** Pandas  
- **Machine Learning:** Cosine Similarity
